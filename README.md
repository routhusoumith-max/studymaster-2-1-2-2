# StudyMaster — React 2-1 & 2-2 Study Management System

## Run
```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Features
- Semester switch: 2-1 / 2-2
- Editable syllabus and units
- Class-work timetable
- Internal exam timetable
- Revision timetable
- Completion tracking and progress ring
- Search
- Dark/light mode
- LocalStorage auto-save
- JSON backup export
- Responsive mobile layout

## Important
The 2-1 subjects are starter data based on the subjects you previously mentioned (DBMS, OOPS, SE, MSF, COA).
The 2-2 subjects are editable placeholders. Replace them with your official syllabus.
Internal exam dates are intentionally placeholders until you enter the official college schedule.
